### 측정 B. 포트홀 밝기와 색

방법: 정답 상자 안 모든 픽셀과 바깥 고리(폭 d는 고리 넓이 = 상자 넓이가 되게 (w + 2d)(h + 2d) = 2wh, 최소 8px = 노면 마스크 흐림 σ 3px의 두 배보다 넓게. 파이프라인 노면 마스크 안, 다른 정답 상자 밖 픽셀만, 50개 미만이면 뺌)의 CIE Lab(L 0~100) 평균을 비교한다. ΔL = 안 − 바깥, ΔE = CIE76, 질감 비 = 7×7 지역 표준편차 중앙값의 안 ÷ 바깥. '차이 작음' = |ΔL| < 5(색차를 알아보는 한계 ΔE ≈ 2.3의 약 두 배. 가짜 대조군 |ΔL|의 75백분위가 2.7, 90백분위가 5.7이라 일반 노면끼리의 차이와 겹치는 범위). 상자 평균은 정답 상자의 여백 노면과 섞여 희석되므로 **픽셀 단위**도 쟀다: 노면 마스크와 같은 σ 3으로 흐린 Lab에서 고리 평균색과의 ΔE가 고리 픽셀 자신의 95백분위를 넘는 상자 안 픽셀 비율(다른 픽셀, 노면과 같으면 약 5%)과 그중 밝은 쪽·어두운 쪽. 가짜 대조군 = 같은 크기 상자를 같은 사진의 ROI 안 노면(노면 80% 이상, 정답 상자와 고리 폭만큼 떨어짐)에 무작위(사진 이름 crc32 seed)로 놓고, 자리가 없으면 무손상 개발셋 사진에 놓음(1,060개 중 181개).

#### 평가 지표 추가: 정밀도·F1·F2 (판정 기준은 그대로)

정의(evaluate_train.score_columns·tau_score_columns):
- 후보 단위 정밀도 = 검출 성공 후보 ÷ 전체 후보, 재현율 = 안에 후보가 든 정답 상자 ÷ 전체 정답 상자. 중심 기준(ctr): 후보 상자 중심이 같은 종류 정답 상자 안이면 성공(한 정답 안의 후보 여럿을 모두 성공으로 셈). IoU 기준(iou): IoU ≥ 0.3, 정답 하나에 후보 하나(evaluate.count_matches). '전체'는 균열·포트홀 개수를 더해 낸다.
- F_β = (1 + β²) × 정밀도 × 재현율 ÷ (β² × 정밀도 + 재현율). F1은 β = 1, F2는 β = 2(재현율을 더 무겁게). 정밀도나 재현율의 분모가 0이면 NaN, 둘 다 0이면 0.
- 영상 단위 혼동 행렬: TP = 손상 영상 검출 성공, FN = 손상 영상 검출 실패, FP = 무손상 영상에 후보 있음, TN = 무손상 영상에 후보 없음. 영상 정밀도 = TP ÷ (TP + FP), 영상 재현율 = 민감도, 영상 F1·F2는 이 둘로.
- 열: train_summary·per_source·tau_curve·tau_points의 맨 뒤(SCORE_COLUMNS·TAU_SCORE_METRICS). τ 곡선의 IoU 기준 열은 τ마다 일대일 매칭을 다시 한다(dev 한 실행 약 6분).
- 회귀 확인: e5_supp_dev와 같은 config로 새 코드를 돌린 v5_scores_dev에서 기존 열이 train_summary·per_source·train_detail·tau_curve·tau_points·tau_images 6개 파일 모두 칸 하나까지 같고(시간 열 제외), 새 열은 맨 뒤에만 붙었다. 운영점(config τ) 행의 새 열 25개가 요약 표와 모두 같다. 저장된 train_detail.csv로 다시 계산한 값(table21)도 새 실행의 요약과 같다.
